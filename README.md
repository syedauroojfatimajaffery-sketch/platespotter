# Plate Spotter

## Overview

Plate Spotter is a web-based food discovery platform developed as an academic project using ASP.NET Web Forms. The platform helps users explore popular food destinations in Hyderabad by providing information about restaurants, cuisines, specialties, and location details.

## Features

* Browse famous food locations in Hyderabad
* View restaurant information and specialties
* Explore different cuisine categories
* User-friendly web interface
* Database-driven content management

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* ASP.NET Web Forms (ASPX)
* C#

### Database

* SQL Server

## Project Structure

* `Default.aspx` – Main webpage interface
* `Default.aspx.cs` – Backend logic
* `Default.aspx.designer.cs` – Auto-generated control definitions
* `Content/` – Stylesheets and design resources
* `Images/` – Project images and media files
* `Properties/` – Project configuration files
* `Web.config` – Application configuration
* `Platespotter.sln` – Visual Studio solution file
* `Platespotter.csproj` – Project file
* `Platespot_database_sql.txt` – Database scripts and queries

## Academic Information
